# Kế hoạch Triển khai Trang Bio Link Cá Nhân (Minimalist Clean)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng trang Bio Link cá nhân phong cách Minimalist Clean hoàn chỉnh, tối ưu di động, có nút TikTok, modal quét mã QR donate kèm tính năng sao chép số tài khoản một chạm, và hướng dẫn chi tiết deploy lên Vercel miễn phí.

**Architecture:** Sử dụng kiến trúc web tĩnh Zero-config (HTML5 + Tailwind CSS qua CDN + Vanilla JavaScript). Tài nguyên hình ảnh mẫu định dạng SVG sắc nét được đặt trong thư mục `assets/`. Tất cả mã nguồn giao diện và xử lý tương tác được đóng gói sạch sẽ trong `index.html`.

**Tech Stack:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript, SVG Icons (TikTok, Check-circle, Coffee, Copy, Close), GitHub, Vercel.

**Spec:** [docs/superpowers/specs/2026-11-04-bio-link-design.md](file:///C:/Users/Administrator/.gemini/antigravity-cli/scratch/bio-link/docs/superpowers/specs/2026-11-04-bio-link-design.md)

## Global Constraints

- Không dùng build tool hay cài đặt npm bắt buộc; trang phải chạy ngay khi mở file `index.html` trên bất kỳ trình duyệt nào.
- Responsive hoàn hảo từ màn hình di động nhỏ nhất 320px đến máy tính để bàn (Mobile-First).
- Toàn bộ vị trí cấu hình (tên, link TikTok, STK, ngân hàng) đều có ghi chú (comment) tiếng Việt rõ ràng.

## Review Focus

1. Trình duyệt không hỗ trợ `navigator.clipboard`: Cần có cơ chế fallback sao chép thông qua `document.execCommand('copy')` để không bị lỗi trên các trình duyệt cũ hoặc webview TikTok in-app.
2. Trải nghiệm chạm trên điện thoại: Modal đóng mở mượt mà, không bị giật lag, nền mờ khoá cuộn trang (prevent background scroll) khi modal mở.
3. Liên kết TikTok: Phải có thuộc tính `target="_blank"` và `rel="noopener noreferrer"` để mở tab mới an toàn.
4. Ảnh đại diện và mã QR: Có ảnh SVG dự phòng sẵn sàng hiển thị ngay cả khi người dùng chưa kịp thay ảnh cá nhân.
5. Hướng dẫn deploy Vercel: Rõ ràng từng bước cho người mới bắt đầu không rành kỹ thuật.
